PYTHON STRING REVERSAL — QUICK REFERENCE

Slice (recommended):       reversed_text = text[::-1]
Built-in iterator:         reversed_text = "".join(reversed(text))
Reverse word order:        reversed_words = " ".join(text.split()[::-1])
Simple palindrome check:   is_palindrome = text == text[::-1]

Python strings are immutable and have no reverse() method. list.reverse()
changes a list in place, while reversed(text) returns an iterator. See
README.md and reverse.py for complete, tested examples.
