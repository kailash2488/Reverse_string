# Contributing

Thank you for helping make this learning project better.

1. Fork the repository and create a focused branch.
2. Make your change with clear names and beginner-friendly comments.
3. Add or update tests when behavior changes.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request explaining what changed and why.

Bug fixes, documentation improvements, well-explained techniques, and Unicode examples are welcome. Keep each pull request small and avoid dependencies when the standard library is enough.
